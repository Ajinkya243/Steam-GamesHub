# 🎮 Steam Games Hub - Full Stack Game Store

**Steam Games Hub** is a full-stack e-commerce web app for browsing and managing games. Users can explore game listings, add games to cart or wishlist, and manage their shopping experience. Built using React for the frontend and Node.js + Express + MongoDB for the backend.

🔗 [Live Demo](https://steam-games-hub.vercel.app/)

Backend repository - https://github.com/Ajinkya243/Steam-GamesHub-Backend

---

## ✨ Features

### 🛍️ Frontend
- Browse all games
- Add/remove games from cart
- Add/remove games from wishlist
- Filter and sort by genre, rating, and price
- Responsive and interactive UI
- Razorpay Payment gateway 

### 🔐 Backend
- Game data managed through MongoDB
- RESTful APIs using Express
- Backend hosted separately
- Future-ready for user auth and checkout flow

---

## 🛠️ Tech Stack

### Frontend
- React
- React Router
- React Hooks
- Context API
- CSS Modules / Plain CSS

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- CORS, dotenv
